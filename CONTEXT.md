# Synara

Synara is a workspace for running conversations alongside the tools and project material needed to complete them.

## Language

**Right sidebar**:
The secondary workspace to the right of the main conversation, where Terminal, Browser, Files, Side chats, iOS Simulator, and Source control can be opened.
_Avoid_: Side panel, Sidebar

**Right-sidebar workspace**:
The Project-owned collection of open tools, their visible arrangement, and the working context inside each tool in the Right sidebar. It remains the same when the user moves between Main conversations in that Project and is restored when Synara restarts.
_Avoid_: Thread sidebar state, Session sidebar state

**Main conversation**:
The primary workspace where the user and agent exchange messages and compose prompts.
_Avoid_: Main panel
