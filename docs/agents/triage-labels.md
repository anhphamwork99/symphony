# Triage labels

Matt workflow skills use these labels for Local Markdown tickets:

| Role              | Label             | Meaning                                                            |
| ----------------- | ----------------- | ------------------------------------------------------------------ |
| Needs triage      | `needs-triage`    | A maintainer must evaluate the ticket.                             |
| Needs information | `needs-info`      | The ticket is waiting for more information.                        |
| Ready for agent   | `ready-for-agent` | The ticket is fully specified and can be implemented autonomously. |
| Ready for human   | `ready-for-human` | The ticket requires human implementation or a human-only action.   |
| Won't fix         | `wontfix`         | The ticket will not be actioned.                                   |
